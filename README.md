# Panel Quest

A Level 2 graphic-novel studio for grades 6–8 from **The Stories of M.E.**

Kids jump inside a comic box, stamp a neon cover, drop a city and a star, write a title, then build boxes until the last one is a close-up hook. They walk out with a real book.

This repo is **Panel Quest only**. It is not the parent site (`thestoriesof-me`).

## Show it to Lovable

1. Open [Lovable](https://lovable.dev).
2. **New project → Import from GitHub**.
3. Pick **`jmonrulz360-coder/panel-quest`**.
4. Do **not** import this into `thestoriesof-me` or push it onto that repo's `main`. That site stays separate.

If Lovable asks for GitHub access, connect the `jmonrulz360-coder` account (the same one already used for the parent site).

## Run it locally

```bash
npm install
npm run dev
```

Then open the HQ and tap **Jump inside**.

## What kids do

1. **Cover press** — city, star, title, slam.
2. **Walk into a box** — Setup → Trouble → Hook.
3. **Art first** — city + character before anyone talks.
4. **Stamp** — add the next box, or finish on a close-up.
5. **Read the book** — cover, pages, director's note.
